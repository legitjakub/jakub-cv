Agentic commerce
on Shopify, without the fog.

AI agents in ChatGPT, Copilot, Gemini or right in the browser can already search Shopify stores, and on some channels they can pay too. This page shows how that shopping journey works, what is available today and what it means for a store in Czechia or the wider EU.

What this means for a Czech store
Czech shoppers are not excluded
AI Mode and Gemini are available in Czechia and in Czech. Shop is also available to Czech customers. App availability alone does not guarantee product recommendations or direct checkout.
Four separate requirements
Distinguish access to the app, product discovery, merchant eligibility and purchase completion. Google uses Merchant Center; direct checkout has a narrower geographical scope.
Shop is not Shop MCP
Shop is a shopping app and website. Shop MCP is an interface for developers of personal agents, including sign-in and authorised Shop Pay purchases.

Who does what

Different layers,
different roles.

Articles mix these names up. Each one actually covers a different layer, and only some of them concern the merchant directly.

Data

Shopify Catalog

Available

Global Catalog searches across merchants; Storefront Catalog searches one store. Both implement UCP Catalog capabilities. search_catalog searches, lookup_catalog resolves known identifiers and get_product explores products and variants. Google uses Merchant Center for its own product discovery.

Concerns you directly. Your store’s data goes into Catalog; Fall ’26 added an eligibility check that shows what to fix.

Shopify Help Center: Agentic storefronts · Shopify Editions Fall ’26

Global Catalog · Storefront Catalog · Google Merchant Center

Channels

Agentic Storefronts

Available, subject to channel requirements

The part of the Shopify admin (Sales channels > Agentic) where you decide which AI channels get your data and direct checkout.

Default activation applies to available options for eligible stores. The separate Agentic plan starts with direct checkout disabled. Neither eligibility nor activation guarantees a recommendation.

Shopify Help Center: Agentic storefronts

Connection

MCP

Open protocol

Model Context Protocol: a general way for an AI model to call tools and read data. Not specific to commerce.

Indirectly. Agents connect to Shopify over MCP; since 13 Oct 2026 Shopify also offers a hosted Shop MCP.

Model Context Protocol · Shopify.dev Changelog, 13 Oct 2026: Shop MCP

Commerce rules

UCP

Open standard

Universal Commerce Protocol defines commerce capabilities for catalogues, carts, checkout and orders. It supports REST, MCP, A2A and embedded transports and bindings; participants negotiate the tools and versions they support.

Indirectly. Shopify implements it for you; a custom agent or app works with it.

Universal Commerce Protocol · Shopify.dev: Agentic commerce

Browser

WebMCP

Experiment (origin trial)

A proposed web standard that lets a page offer tools to an agent in the browser, instead of the agent clicking blindly.

Chrome documents an origin trial from version 149. Shopify introduced checkout tools on 28 Sep 2026, but use requires a compatible browser, agent and implementation. This remains an experimental web API, not a generally available sales channel.

Chrome for Developers, 9 Jun 2026: WebMCP origin trial · Shopify.dev Changelog, 28 Sep 2026: WebMCP for checkout

Interface

Ask MCP

UCP draft

ask_business answers questions about policies and services using the store’s Knowledge Base and policies. It changes neither carts nor orders or returns. It is absent from dated UCP releases: the profile must declare draft and dev.ucp.common.ask, and the merchant must actually offer the tool.

Ask MCP · draft · Knowledge Base

Interface

Order MCP

Restricted access

get_order reads only orders placed through this agent. It requires Token tier, a Global API JWT with read_global_api_orders, the declared capability and Shopify-Buyer-IP on merchant calls. It is not a buyer’s universal order history. Webhooks are the primary update channel; Shopify registers their URL and topics through a partner manager, rather than a self-service API or a webhook_url in the profile alone.

Order MCP · Auth tiers · Order webhooks

Interface

Shop / Shop MCP

Two distinct products

Shop is a consumer app and website, with Catalog products and its own selling settings. Shop MCP is a hosted interface for personal agents at mcp.shop.com. Search needs no API key; Shop sign-in enables personal features and authorised Shop Pay purchases. search_orders supports a signed-in shopper’s orders and tracking; get_checkout checks a particular checkout. The launch announcement says Shop MCP has no webhooks yet — that limitation must not be applied to Order MCP.

What to do

Practical steps
for merchants.

Most of these improve the store even without AI channels. None of them promises visibility or sales; each channel ranks offers by its own rules.

  1. 01

    Check participation

    In Sales channels > Agentic, separate Catalog status, enabled channels and direct checkout. Shop also has its own selling settings.

  2. 02

    Decide by shopper market

    Business location is not the shopper’s country. Use the table to distinguish app access, product recommendations and purchase completion.

  3. 03

    Improve product data

    Start with titles, descriptions, images, prices and variants. Map metafields only to supported fields; they do not automatically become filters.

  4. 04

    Review public facts

    Complete policies, review Knowledge Base publication and automatic discovery files. Keep internal information private.

  5. 05

    Check prices and discounts

    Review Catalog list price settings and legally required price history. A compare-at price alone does not establish a discount.

  6. 06

    Test the actual journey

    Check discovery, cart, merchant checkout and any direct payment for the target country. Treat WebMCP as an experiment.

  7. 07

    Measure the results

    Use Search Preview and available reports. Catalog output is not the actual ranking in every AI app; headless analytics have limits.

Eligibility: the store and the product are separate

For an ordinary store, Catalog requires Starter or higher and a public storefront. The separate Agentic plan is an exception that permits inclusion without a published Shopify storefront, with external product URLs. Plus is not required.

  • Account: verified email, two-step authentication, a passkey where available, and identity / business verification when requested. Genuine sales history, prompt fulfilment, low chargebacks, paid invoices and good account standing matter. Shopify publishes no universal minimum order count or numerical chargeback threshold.
  • Product: a title, at least one image, a price above zero, an identifiable URL and publication to Online Store, Hydrogen or Headless. It must not be Unlisted, hidden from search engines or in a prohibited category. Complete descriptions and available variants improve quality; minimum eligibility does not guarantee recommendations.

Catalog requirements

agents.md, llms.txt and llms-full.txt

Shopify generates these automatically. /agents.md is the canonical discovery URL; /llms.txt and /llms-full.txt serve compatible crawler conventions and return the same content by default: store name and URL, sitemap, policies and discovery endpoints.

The agents.md.liquid template changes the default content of all three URLs. llms.txt.liquid and llms-full.txt.liquid take precedence for their specific URL. These files replace neither Shopify Catalog nor a product feed or channel integration.

Agent discovery files

Knowledge Base: publish public information only

Manage it in Sales channels > Agentic > Sources > Knowledge Base. Published facts are publicly available through Storefront MCP. Facts from storefront scans start unpublished; facts linked to the admin, such as policies and contacts, are published when created. You can publish or unpublish individual fields, categories or all facts and approve suggested updates.

The limit is 1,000 facts in total. The legacy Knowledge Base app is no longer available to install; its documented deprecation date is 15 Jan 2027. With up to 1,000 facts, custom facts and overrides transfer and publish automatically; larger sets need manual review and completion.

Do not add internal information, private price lists, credentials or sensitive business or customer data.

Knowledge Base · Legacy app migration

Metafields and variant grouping

In Review product data mapping, select Shopify Catalog and check the supported title and description sources. You can use product fields, metafields or combined sources. Missing values fall back to the default source. Product category cannot be mapped for Shopify Catalog here.

Custom variant grouping combines separate products into a listing using supported fields, metafields, titles or tags. The preview checks data received by Catalog, not its exact presentation in every AI app. An arbitrary custom metafield does not automatically become a searchable attribute or filter for all agents.

Catalog data mapping · Catalog tools

Search Preview and measurement

Open Sales channels > Agentic and Search preview. Try realistic buyer queries: product type, intended use, attributes, dimensions or availability. Review returned products and quality checks for descriptions, images, variants, reviews and policies. Fix missing data or mapping and repeat the query.

This is raw Shopify Catalog search output, not a guarantee of ranking in ChatGPT, Google or another app. Each channel selects and presents products independently. Agentic reports distinguish sales, orders and sessions; the documentation currently says Agentic performance analytics are unavailable for headless stores.

Prices, compare_at_price and the Czech 30-day rule

price is the current selling price; compare_at_price is a comparison price, not proof of a previous price or a legally valid discount. Catalog mapping lets you choose Price or Compare-at price as list price; the latter applies only when higher than the current price. AI channels may use it for strikethrough pricing.

When announcing a discount to Czech consumers, § 12a of Act No. 634/1992 requires the lowest price in the preceding 30 days and a discount calculated from it. For newer products, use the lowest price since sales began; for continuous progressively increased discounts, the reference precedes the first reduction. The exception for rapidly perishable goods or short shelf life does not exempt all food.

Passing a comparison price to an AI channel replaces neither price history nor correct discount presentation or legal compliance.

Frequently asked questions

Common
questions.

Do I need to switch anything on for Shopify agentic commerce?

For an ordinary eligible store, available Agentic Storefronts options are active by default. Check Catalog, channels and checkout in Sales channels > Agentic; the separate Agentic plan starts with direct checkout disabled. Shop has its own settings, and this Shopify ChatGPT integration does not offer direct checkout.

Can customers in Czechia shop this way?

Yes, for example through Shop or a referral to the merchant’s checkout. AI Mode and Gemini are available in Czechia and in Czech. App access, product recommendations and direct checkout have different requirements; availability of one does not establish the others.

Do I need Shopify Plus?

No. Ordinary Shopify Catalog eligibility starts at Starter; the separate Agentic plan has its own conditions. The store, account, products and channel must meet their requirements. A subscription plan alone guarantees neither inclusion nor recommendations.

What is the difference between MCP, UCP and WebMCP?

MCP connects AI to tools and data. UCP defines commerce capabilities and multiple transports, including MCP. WebMCP exposes tools in the browser and Chrome still documents it as an origin trial. Ask MCP is additionally a UCP draft, not a universally available stable feature.

Is Shop the same as Shop MCP?

No. Shop is a consumer shopping app and website. Shop MCP is an interface for personal agents, with catalogues, carts, checkout and signed-in order search. Its capabilities differ from Order MCP, which reads only orders placed through that particular agent.

Will better data guarantee higher sales?

No. Complete data helps channels interpret an offer, but each channel selects and ranks products independently. Search Preview checks Shopify Catalog output; it guarantees neither actual placement nor commercial results.
